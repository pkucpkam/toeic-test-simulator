# TOEIC Test Simulator

Dự án này là một ứng dụng web được tạo ra với mục đích cá nhân để tự ôn thi TOEIC.

## Tính năng
- Làm bài thi thử TOEIC mô phỏng thực tế.
- Chấm điểm tự động và xem lại các câu trả lời sai.
- Giao diện thân thiện và dễ sử dụng để luyện tập mỗi ngày.

## Cấu trúc dự án
- `/frontend`: Chứa mã nguồn giao diện web (React / Next.js).
- `/backend`: Chứa mã nguồn máy chủ xử lý dữ liệu (Java Spring Boot).
- `/database`: Chứa các script khởi tạo và migrate dữ liệu cơ sở dữ liệu (PostgreSQL).

## Lưu ý
Repo này được phát triển hoàn toàn với mục đích cá nhân nhằm cải thiện kỹ năng lập trình và tự luyện thi TOEIC, không phục vụ cho mục đích thương mại.
